# 提示词笔记本

一个无需登录、仅在访客本机保存数据的静态提示词笔记本，适合 GitHub Pages。公共版本不包含任何人的初始笔记。

支持标题主页、内容编辑与复制、标签颜色、搜索、收藏置顶、回收站、确认清空、JSON 导出/导入、关联本地数据文件、历史恢复及离线网页缓存。

## 数据保存

- 修改立即写入本机 `localStorage`，随后写入本机 IndexedDB；写入失败会明确提示。
- IndexedDB 使用事务，保留上一版本及近期恢复点，并验证恢复副本校验码。
- 多窗口使用浏览器 Web Locks 限制为一个编辑窗口；其他窗口可查看实时更新。
- “保护本机存储”请求浏览器持久存储权限；是否批准由浏览器决定。
- Chrome/Edge 等支持 File System Access API 的浏览器可关联独立 JSON 数据文件。其他浏览器可导出/导入 JSON 备份。
- Service Worker 只缓存本项目静态页面文件，不缓存或传输笔记。

**不能承诺绝对不丢失：** 浏览器的两处存储属于同一设备。主动清除网站数据、无痕模式、卸载浏览器或设备损坏都可能导致丢失。独立文件备份才可在这些情况下恢复。建议至少每周导出一次，或关联本地数据文件。

换设备、换浏览器配置或换域名不会自动同步。共用同一浏览器配置的人能看到相同笔记；笔记不加密。历史恢复点及独立备份可能保留已从回收站清除的旧笔记。

## 隐私

无登录、无分析脚本、无外部依赖、无笔记上传 API。访问网站会向 GitHub Pages 请求网页资源，GitHub 作为托管方可处理通常的访问日志；笔记标题和内容不会随这些请求发送。

代码仅加载同站静态资源。部署更新不清空本机笔记或恢复点。不要将网站迁移到新域名后声称数据自动迁移。

## 发布与验证

使用 GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 禁用不必要的静态构建。无需后端、运行时依赖、API 密钥或付费服务。

```sh
npm ci --ignore-scripts
npm test
```

修改网页资源时，应更新 `sw.js` 的缓存版本。不要删除或更换 `app.js` 中已有的数据存储标识，否则现有用户将无法自动读取旧数据。
